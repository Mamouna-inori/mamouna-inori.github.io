# まもうな OFFICIAL WEB SITE

PowerPointで車内LCD（トレインビジョン）を再現するクリエイター「まもうな」のオフィシャルウェブサイトです。
水瀬いのりオフィシャルウェブサイト（inoriminase.com）の洗練されたトーンをベースに、清潔感のあるクリーンなデザインで構成されています。

---

## 主な構成

- **PROFILE**: 自己紹介、各種公式SNSへのリンク（YouTube, X, Instagram, Freedom Train, Mail）
- **MOVIE (最新動画)**: 公式YouTubeチャンネル（`@Mamouna_Inori`）の最新動画をPC横3列で表示（自動取得機能付き）
- **ARTICLES (記事一覧)**: [Freedom Train 著者ページ](https://freedomtrain.jp/author/mamouna_owo/) の執筆記事一覧（高画質サムネイル・著者ページへの直リンク付き）
- **OFFICIAL SNS**: 公式X (Twitter) のタイムライン埋め込み & Instagram プロフィール
- **BOOK (同人誌)**: 『PowerPointではじめる車内LCD再現』（C106 / C108）の紹介
- **CONTACT & GUIDELINES**: お問い合わせ窓口、二次利用のガイドライン

---

## 開発と実行

静的HTML/CSS/JavaScriptで構築されているため、ブラウザで直接開くか、Pythonの簡易サーバー等でプレビューできます：

```bash
py -m http.server 8000
```

GitHub Pages（CNAME: `mamouna.net`）にてそのまま配信されます。
